## Tugas 3
1. ModelForm digunakan karena form tersebut dapat dibuat berdasarkan model Django yang sudah ada, jadi field yang tersedia pada form bisa disesuaikan dengan field pada model tanpa harus bikin setiap input HTML secara manual. Dengan ModelForm, proses validasi dan pengolahan data form juga lebih mudah karena sudah terhubung dengan model. Sementara itu, {% csrf_token %} wajib ditambahkan pada form yang menggunakan method POST untuk memberikan perlindungan terhadap serangan Cross-Site Request Forgery (CSRF). Token tersebut memastikan bahwa request yang dikirim berasal dari form pada aplikasi kita dan bukan dari sumber lain yang mencoba mengirim request secara tidak sah.

2. JSON lebih banyak digunakan dalam pengembangan aplikasi web modern karena formatnya lebih sederhana dan ringkas dibandingkan XML. Struktur JSON juga lebih mudah dibaca oleh manusia dan lebih mudah diproses oleh JavaScript karena menggunakan format key-value dan array yang mirip dengan struktur data pada JavaScript. Selain itu, JSON biasanya menghasilkan data yang lebih ringan, jadi akan lebih cocok cocok digunakan untuk pertukaran data antara server dan client, misalnya ketika aplikasi mengambil data melalui API.

3. Saat view digunakan untuk mengembalikan data portofolio dalam bentuk JSON, view terlebih dahulu mengambil data dari model Django. Data tersebut kemudian diproses menggunakan serializers.serialize("json", ...) untuk mengubah object atau queryset Django menjadi data dalam format JSON. Setelah itu, JSON dikembalikan melalui HttpResponse dengan content_type="application/json" sehingga browser atau client dapat mengenalinya sebagai data JSON. Pada implementasi yang menggunakan data tersebut kembali di halaman portofolio, JSON kemudian dapat di-deserialize untuk mengubahnya kembali menjadi object Python/Django sebelum dikirim ke template. Proses serialization diperlukan karena object Django yang berasal dari database tidak dapat langsung dikirim sebagai JSON. Dengan serialization, data model diubah ke format yang dapat dikirim dan dipahami oleh client atau sistem lain.
